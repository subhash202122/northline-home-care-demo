# Northline Home Care - landing page sample

This is a self-initiated portfolio concept built with HTML, CSS, and vanilla JavaScript. Northline Home Care is fictional; this is not a client commission or a production business website.

## Features

- Responsive desktop and mobile layouts
- Mobile navigation menu with accessible state
- Service cards and page section links
- Contact form with required-field and email validation
- Reduced-motion support, skip link, semantic landmarks, and visible keyboard focus
- No build tools or external JavaScript libraries

The sample form runs local browser validation and confirmation only. It does not send, store, or collect submissions.

## Run locally

Open `index.html` in a modern browser. Internet access is needed only to load the optional Google Fonts; system fonts are used as fallbacks.
